# Radar de Aluguel

Site estático para quem procura onde morar em Belo Horizonte. Sem build: `index.html`, `app.js` e `estilo.css`.

Este repositório não guarda dados de anúncios nem dados pessoais. Tudo vem do Supabase, pelas funções `alugar_*`, com o
código do link pessoal. A chave em `app.js` é a chave pública do projeto; as tabelas só abrem por essas funções.

`bairros.geojson`: contornos dos bairros (PBH, dados abertos).
